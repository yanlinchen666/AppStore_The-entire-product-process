# Sample / Cached Data

This directory contains cached sample output so interviewers can view results
even when external network access is unavailable (per README requirement).

⚠️ **These are CACHED SAMPLE results, not live analysis output.**
The application retains the ability to process previously unseen inputs when
the required network and model configuration is available.

## Files

| File | Description |
|------|-------------|
| `sample_reviews.json` | A small dataset of App Store reviews (10 entries) for the Workout for Women app, used to demonstrate the import + analysis flow without network access. |
| `sample_analysis_result.json` | A complete cached analysis output (topics, findings, requirements, test cases) generated from the sample reviews, demonstrating what the full pipeline produces. |

## How to use

### Option A: Import sample reviews and run live analysis
```bash
# 1. Start backend
cd backend
python -m uvicorn app.main:app --reload

# 2. Via API: import the sample reviews
curl -X POST http://localhost:8000/api/import \
  -F "file=@sample_data/sample_reviews.json" \
  -F "format=json"

# 3. Via API: analyze the imported reviews
curl -X POST "http://localhost:8000/api/import/analyze?app_id=839285684&app_name=Workout%20for%20Women&analysis_goal=Analyze%20subscription%20and%20usability%20issues"
```

Or via the UI:
1. Open http://localhost:5173/import
2. Upload `sample_data/sample_reviews.json`
3. Click "开始分析导入的数据"

### Option B: View cached results directly (no network / no API key required)
Open `sample_analysis_result.json` to inspect a representative output of the
full pipeline (topics → findings → requirements → test cases), including:
- Evidence-backed findings with `evidence_review_ids`
- Findings marked as `is_assumption: true` when evidence is insufficient
- Requirements linked to findings via `finding_id`
- Test cases linked to requirements via `requirement_id`
- Complete traceability chain from review → finding → requirement → test case

## Data source

The sample reviews in `sample_reviews.json` are real App Store reviews for the
app "Workout for Women: Home Gym" (App ID: 839285684), collected via the
iTunes RSS Customer Reviews API on 2025-01-15.

The cached analysis result was generated by running the full pipeline with:
- LLM: Qwen/Qwen3-8B via SiliconFlow
- Embeddings: BAAI/bge-m3 via SiliconFlow
- Vector DB: ChromaDB (local)
